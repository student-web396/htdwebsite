#  Hetauda City College Website

This project is a dynamic college website developed to showcase the facilities, services, and essential information of Hetauda City College.


## Features

* College Information
  Displays details about the college, courses, and overall environment.

* Facilities Showcase
  Highlights key facilities such as:

  * Library
  * Playground
  * Classrooms
  * Other infrastructure

* User-Friendly Interface
  Clean and simple design built using HTML and CSS for easy navigation.
## 🛠️ Tech Stack

* Frontend: HTML, CSS
* Backend:PHP
* Database:MySQL
* Server Environment: XAMPP / Localhost

## Installation & Setup

1. Clone the repository:
```bash
git clone https://github.com/your-username/hetauda-college-website.git
```
2. Move the project to your XAMPP `htdocs` folder
3. Start Apache and MySQL from XAMPP
4. Import the database:

   * Open phpMyAdmin
   * Create a new database
   * Import the provided `.sql` file
5. Run the project in browser:
```bash
http://localhost/hetauda-college-website
